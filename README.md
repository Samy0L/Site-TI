# Cățeluș cu părul creț — CSR landing page

Versiune refăcută cu direcție vizuală navy/blue, folosind materialele existente ale proiectului.

## Materiale integrate
- Flyer-ul existent al proiectului, afișat în hero și în secțiunea Materiale.
- Propunerea existentă de proiect, afișată în secțiunea Materiale.
- PDF-urile originale sunt păstrate în `assets/docs/` și pot fi deschise direct din pagină.

Conținutul paginii este bazat pe materialele proiectului: serie video 2–5 minute, teme de integritate, grup țintă 6–16 în flyer, respectiv 10–18 în propunerea detaliată, distribuție prin școli/rețele sociale și parteneriate CSR. Pentru a evita reconcilierea artificială a documentelor, valorile diferite au fost păstrate doar acolo unde apar în sursa respectivă.
